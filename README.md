## 📖 О проекте

**StudyRemote** разработан специально для студентов и разработчиков, которым нужно контролировать свой ПК во время пар в университете:
- **Zero Client**: Не нужно устанавливать приложения на телефон или чужой университетский ноутбук — открывается прямо в Chrome, Safari, Firefox или Edge.
- **Минимальный расход мобильного интернета**: адаптивное сжатие JPEG (всего 15–30 КБ на кадр) позволяет плавно работать даже через нестабильный 3G/4G.
- **Встроенный туннель Cloudflare**: автоматическая генерация публичной ссылки `https://*.trycloudflare.com` — работает сквозь любые университетские файрволы без белого IP и без открытия портов на домашнем роутере.

## ✨ Особенности

- 🖥️ **Быстрый стриминг экрана**: захват через библиотеку `MSS` (~60 FPS, 16 мс на кадр) и отображение через HTML5 Canvas.
- 🖱️ **Полноценное управление мышью и тачем**: клики, правый клик (долгое нажатие), свайпы курсором, колесо мыши.
- ⌨️ **Экранная клавиатура и горячие клавиши**: быстрые кнопки `Ctrl+C`, `Ctrl+V`, `Win+L` (блокировка ПК), `Alt+Tab`, `Enter`, `Esc` и отдельное поле для мгновенной отправки текста.
- 💻 **Удалённый Web-терминал**: выполняйте консольные команды (`git status`, `git pull`, `npm run dev`, `tasklist`) прямо из браузера.
- 📁 **Файловый менеджер**: просмотр файлов на диске, скачивание и выгрузка.
- 📊 **Мониторинг ресурсов**: загрузка CPU, оперативной памяти (RAM) и свободного места на диске в реальном времени.
- 🔒 **Защита доступа**: вход по секретному PIN-коду (по умолчанию: `1234`).
- 📦 **Автономный бинарник**: файл `dist/StudyRemote.exe` работает без необходимости устанавливать Python на компьютер.

## 🚀 Быстрый старт

### Способ 1: Запуск готового EXE файла
1. Перейдите в папку `dist` и запустите **`StudyRemote.exe`** (или запустите **`run.bat`** в корне).
2. В консоли отобразятся доступные адреса:
   ```text
   [*] Локальный адрес:  http://localhost:8080
   [*] Адрес в сети:      http://192.168.1.42:8080
   [*] Защитный PIN-код:  1234
   ```
3. Откройте указанный адрес в браузере смартфона (если в одной Wi-Fi сети) или запустите с параметром `--tunnel` для доступа через интернет.

### Способ 2: Запуск с публичным туннелем (для доступа с пар)
Запустите `run.bat` и выберите пункт **[2]** (или выполните команду):
```bash
dist\StudyRemote.exe --tunnel
```
Сервер автоматически запустит Cloudflare Tunnel и выдаст готовую ссылку:
```text
🌐 ПУБЛИЧНАЯ ССЫЛКА ДЛЯ ДОСТУПА С ПАР:
https://random-subdomain.trycloudflare.com
```
Открывайте эту ссылку на телефоне на парах, вводите свой PIN (`1234`) и работайте!

## 🛠️ Сборка в .EXE файл

Если вы внесли изменения в код и хотите перекомпилировать исполняемый файл:

1. Убедитесь, что установлены зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите скрипт сборки:
   ```bash
   build.bat
   ```
   *Скрипт автоматически запустит PyInstaller с нужными флагами и положит готовый бинарник в `dist/StudyRemote.exe`.*

## 🐙 Как залить этот проект на GitHub

Чтобы выложить этот проект в свой личный репозиторий GitHub, выполните следующие команды:

### 1. Создайте пустой репозиторий на [GitHub](https://github.com/new)
* Назовите его, например, **`StudyRemote`**.
* **Не ставьте галочки** на «Add README» или «Add .gitignore» (они уже есть в папке!).

### 2. Инициализируйте и отправьте код
Откройте терминал (PowerShell или CMD) в папке `StudyRemote` и введите:

```bash
# 1. Инициализация локального репозитория
git init

# 2. Добавление всех файлов в коммит
git add .

# 3. Создание первого коммита
git commit -m "feat: initial commit StudyRemote v1.0"

# 4. Переименование главной ветки в main
git branch -M main

# 5. Привязка к вашему GitHub репозиторию (замените ссылку на свою!)
git remote add origin https://github.com/ВАШ_НИК/StudyRemote.git

# 6. Отправка на GitHub
git push -u origin main
```

> **Совет по размеру файлов на GitHub**:  
> Исполняемый файл `dist/StudyRemote.exe` весит около 64 МБ, что полностью укладывается в стандартный лимит GitHub (до 100 МБ на файл).  
> Если в будущем вы захотите выкладывать сборки отдельно, можно использовать раздел **Releases** на странице репозитория.

## ⚙️ Параметры командной строки

| Флаг | Значение по умолчанию | Описание |
|------|------------------------|----------|
| `--port` | `8080` | Порт локального веб-сервера |
| `--pin` | `1234` | Секретный PIN-код для входа |
| `--tunnel` | `False` | Автоматически запустить Cloudflare Quick Tunnel |

Пример запуска:
```bash
StudyRemote.exe --port 5000 --pin 7788 --tunnel
```
